# 2025 Angler Survey Infographic Icons Registry

This registry documents the SVG vector assets created for the 2025 Angler Survey Trends Infographics.

All icons conform strictly to the design system constraints:
- **Stroke Width**: Exactly `2px` for all paths and shapes.
- **Color & Fill**: Uses `stroke="currentColor"` and `fill="none"` to allow for dynamic HTML color-theming.
- **Cap & Join**: Uses `stroke-linecap="round"` and `stroke-linejoin="round"`.
- **Viewport**: Set to `0 0 24 24`.
- **Content**: Clean, geometric paths with absolutely no text, brands, or logos.
